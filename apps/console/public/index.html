GUIDE

如何为 Agent 创建 Agent DID

三步完成。Agent DID 由 Agent 自己创建，不需要先有 DataDID。
1

安装独立 Skill

npx skills add memoio/agent_did_skill --skill memo-agent-did-mainnet
node <Skill目录>/scripts/setup-runtime.mjs --json
2

确保本地身份

memo-agent-mainnet doctor --json
memo-agent-mainnet identity ensure --json
memo-agent-mainnet identity status --json
3

接受 Invitation 或创建 Offer

memo-agent-mainnet pair invitation accept --invitation-file invitation.json --json
# 或 pair offer create --offer-file offer.json ...

协议边界

没有 DataDID 可以吗？
可以。身份、配对和管理流程不依赖 DataDID；它只能是非权威展示。
管理关系是不是资源授权？
不是。Vault、Memory、Data 和 MCP 权限仍由独立 Agent Gateway 管理。
什么时候上链？
本地 ensure 不上链；注册、生命周期和管理关系在 Agent/Manager 完成 EIP-712 签名后，由 Relayer Smart Account 经 Alto 和 EntryPoint v0.7 上链。
